# yt-dlp 工作台

> 把命令行的 yt-dlp 包成一个**本地网页控制台** —— 双击即用，不用记参数。

一个纯本地的视频 / 音频下载工具：左侧粘贴链接、选画质，右侧看实时进度。支持批量、播放列表、剪辑双轨拆分、去水印。基于 Python 标准库实现，**无需安装任何第三方包**；也提供打包好的单文件 exe，下载双击即用。

## 功能特性

- **批量下载**：链接框一行一个，支持视频 / 播放列表 / 频道
- **画质预设**：最佳画质、2160P / 1080P / 720P、仅音频 MP3 / M4A，也能自己填 `-f` 表达式
- **画质优先策略**：同分辨率自动选**最高码率**那一路（B站 1080P 实测比默认选择高 3.5 倍码率），不登录也能拿到平台允许的最高画质
- **解析预览**：先看标题、时长、可用清晰度与码率，点分辨率直接切换画质
- **实时进度**：速度、剩余时间、已下载大小、第几路流，合并 / 转码阶段实时显示
- **任务队列**：默认同时下 2 个（可改），支持取消、重试、打开文件、打开目录
- **高级选项**：整列表下载、字幕（自动字幕 / 嵌入）、封面、元数据、章节、跳过已下载、Cookie、代理、限速、并发片段
- **运行日志**：完整 yt-dlp 原始输出，出错能直接看到原因
- **下载历史**：本地记录，可点开文件
- **一键更新**：页面右上角直接升级 yt-dlp
- **剪辑双轨**：一个链接拆出「纯视频轨 + 纯音频轨」，音画对齐可直接进剪映 / Premiere / 达芬奇
- **去水印（可视化编辑器）**：画面拖框选区域、支持**多个水印**、支持**移动水印轨迹**、可**自动检测**候选区域
- **两种修补引擎**：轻量（空间插值，快）与 AI 修补（LaMa 模型，效果更好但慢）
- **画质提升（AI 超分）**：Real-ESRGAN 2× / 3× / 4× 放大，720P 老片源可拉到 1440P，时长 / 帧率 / 音轨原样保留
- **本地文件导入**：手上已有的视频直接导入队列，去水印 / 画质提升不再局限于刚下载的内容，原文件不会被改动

## 本地文件怎么处理

去水印和画质提升的入口在任务卡片上，所以本地文件要先「进队列」，两种方式都行：

- 点任务队列右上角 **＋ 导入本地文件**，可多选（mp4 / mkv / webm / mov / avi / flv / ts 等）
- 或把文件路径直接粘到左侧链接框点「开始下载」——程序识别出是本地路径后会改走导入

导入后任务直接是「已完成」状态，卡片上有播放 / 去水印 / 画质提升 / 打开目录四个按钮，和下载来的文件完全一样。

> **原文件安全**：导入的文件永远不会被覆盖或删除。去水印结果另存为 `原名_去水印.mp4`，超分结果另存为 `原名.up2x.mp4`。
> 下载来的文件为了不留重复垃圾，去水印是就地替换的——两种行为不同是有意设计的。


## 去水印怎么用

下载完成后，任务卡片上点 **✂** 打开编辑器：

1. **框选**：在画面上拖拽画框，可画多个（多个水印就画多个框）
2. **微调**：拖动框可移动位置，选中后按 `Delete` 删除
3. **移动水印**：把播放头拖到起始时间，点「＋ 记录轨迹点」；再把播放头拖到结束时间、把框拖到新位置，再记一次。两点之间自动线性插值跟随
4. **自动检测**：点「自动检测」，程序分析画面给出候选框（角标 / 半透明覆盖），可删掉多余的
5. **选引擎**：轻量（推荐，快）或 AI（实验性，首次需下载约 200MB 模型）
6. 点「开始处理」

| 场景 | 走哪条路径 | 速度 |
|---|---|---|
| 静态水印（位置不动） | ffmpeg 滤镜（delogo + 锐化补偿） | 快，1 分钟片子约 1–2 分钟 |
| 移动水印（有轨迹） | 逐帧修补（四方向渐变插值） | 中，1 分钟片子约 2–5 分钟 |
| AI 修补 | LaMa onnx 逐帧推理 | 慢，CPU 上每帧约 2–3 秒 |

> 关于效果：静态区域实测可完全去除；移动水印跟随轨迹逐帧修补，复杂背景会有轻微痕迹。
> AI 修补对半透明小面积水印效果更好，纯色大块水印效果有限（模型的强项是「脑补纹理」）。

## 画质提升（AI 超分）怎么用

下载完成后，任务卡片上点 **🔍** 打开面板：

1. **选倍率**：2× / 3× / 4×（面板上直接显示 `当前分辨率 → 目标分辨率`）
2. **选模型**：动漫视频（最快，推荐动漫 / 屏幕录制）、动漫高质量、通用高质量（细节最好但最慢）
3. **首次使用**：点「下载引擎」，程序自动获取 Real-ESRGAN（约 45MB，含三组模型，只需一次）
4. 点「开始提升」，进度在任务列表里看

实现方式是 **抽帧 → 逐帧超分 → 合帧**：

```
ffmpeg 抽帧 (JPEG)  →  realesrgan-ncnn-vulkan 批量超分  →  ffmpeg 合帧 + 音频直通拷贝
```

音轨不重编码（`-c:a copy`），时长、帧率、音画同步与源文件完全一致；输出文件名为 `原名.up2x.mp4`。

| 倍率 / 模型 | 1080P 片源实测速度（RTX 4070 Laptop） | 说明 |
|---|---|---|
| 2× 动漫视频 | 约 1.7 帧/秒 | 默认推荐，1080P→2160P 一晚能跑完一集 |
| 4× 通用高质量 | 约 0.1 帧/秒 | 慢一个数量级，只适合短片 / 单镜头 |
| 纯 CPU | 约为显卡的 1/10–1/20 | 可用，但建议只在短片段上跑 |

> 没有独显也能跑：Real-ESRGAN 用 Vulkan，不依赖 CUDA，核显 / 独显都能加速。
> 超分是「猜细节」不是「还原真相」，文字和细密纹理可能出现轻微涂抹感，倍率越高越明显。

## 快速开始

### Windows 用户（推荐，零依赖）

到 [Releases](https://github.com/yuanshen-123uodo/yt-dlp-workbench/releases/latest) 页面下载 **`yt-dlp-workbench.exe`**（约 68MB），双击即用：

- **无需安装 Python、ffmpeg 或任何其他组件** —— ffmpeg、numpy、onnxruntime 都已内置
- 首次运行会自动下载 yt-dlp（约 18MB，一次性；之后启动只要 2–3 秒）
- 下载的文件保存在 exe 同目录的 `downloads\` 文件夹
- 用完关掉黑色命令行窗口即可停止服务

### 源码运行（Windows 双击 / 其他平台）

双击 **`启动工作台.bat`**，浏览器会自动打开 http://127.0.0.1:8765 。

- 首次运行会自动下载 `yt-dlp.exe` 到 `bin/` 目录（也优先使用你系统里已安装的 yt-dlp）
- 用完直接关掉黑色命令行窗口即可停止服务

### 其他平台 / 手动启动

```bash
# 依赖：Python 3.8+（仅标准库）；yt-dlp（放入 bin/ 或加入 PATH）；ffmpeg 可选但推荐
python server.py
```

## 依赖说明

| 依赖 | 是否必需 | 说明 |
|---|---|---|
| Python 3.8+ | 源码运行必需 | 只用标准库 + numpy；**exe 版不需要** |
| yt-dlp | 必需 | 首次运行自动下载；或 [ releases 页面 ](https://github.com/yt-dlp/yt-dlp/releases/latest) 手动放到 `bin/`；或 `pip install yt-dlp` / `winget install yt-dlp` |
| ffmpeg | 强烈推荐（源码运行） | 高清视频合并音视频、双轨拆分、去水印都靠它。[下载](https://ffmpeg.org/download.html) 后加入 PATH 即可；**exe 版已内置，无需安装** |
| numpy | 移动水印 / AI 修补需要 | exe 版已内置；源码运行 `pip install numpy` |
| onnxruntime + LaMa 模型 | 仅 AI 修补需要 | exe 版已内置 onnxruntime，模型首次使用时下载（约 200MB）；源码运行 `pip install onnxruntime onnx` |
| Real-ESRGAN ncnn-vulkan | 仅画质提升需要 | 首次使用时自动下载到 `tools/realesrgan/`（约 45MB，含三组模型），不占安装包体积 |

> 1080P 以上或会员内容：在「高级选项 → Cookie 来源」选一个已登录该网站的浏览器。
> YouTube 等站点打不开：在「高级选项 → 代理」填本地代理，如 `http://127.0.0.1:7890`。

详细使用说明见 [使用说明.md](使用说明.md)。

## 工作原理

```
启动工作台.bat → server.py（ThreadingHTTPServer，仅监听 127.0.0.1）
                      ├─ 静态托管 web/ 前端页面
                      ├─ 任务队列 + 调度线程（并发可调）
                      ├─ 子进程调 yt-dlp，--progress-template 解析结构化进度
                      └─ ffmpeg 后处理：双轨抽取 / 去水印 / 超分抽帧合帧
```

全程本地运行，不经过任何远端服务器；服务只监听 `127.0.0.1`，外部设备无法访问。

## 常见问题

- **提示找不到 yt-dlp**：确认 `bin/yt-dlp.exe` 存在，或系统 PATH 里有 yt-dlp
- **提示 ffmpeg 缺失**（仅源码运行）：装一个加入 PATH（Windows 可 `winget install Gyan.FFmpeg`）；exe 版已内置 ffmpeg，不会出现此提示
- **去水印没反应**：确认框选区域覆盖了水印（框可以略大一点）；移动水印要记两个以上轨迹点
- **AI 修补提示引擎未就绪**：在编辑器里把引擎切到「AI 修补」，点「下载引擎」等待模型下载（约 200MB）
- **画质提升提示引擎未就绪**：在面板里点「下载引擎」获取 Real-ESRGAN（约 45MB）；下载失败多为网络问题，挂了代理再试
- **超分很慢 / 很长**：任务卡显示的是超分帧进度，1080P 一集通常要几十分钟到几小时；可先用 10 秒片段试效果，满意再跑全片
- **想抓更高画质**：B站 1080P 高码率 / 4K 需要大会员登录，在「高级选项 → Cookie 来源」选已登录的浏览器即可；不登录时工具已自动选平台允许的最高码率
- **导入本地文件没反应**：确认扩展名在支持列表里；网络位置（`\\NAS\...`）映射盘符后再试；文件被其他程序独占打开时读取会失败
- **下载失败**：先点页面右上角「更新」升级 yt-dlp，站点改版后旧版本常失效
- **页面打不开**：确认是通过 bat 启动的，且黑色窗口没关
