# yt-dlp 工作台

> 把命令行的 yt-dlp 包成一个**本地网页控制台** —— 双击即用，不用记参数。

一个纯本地的视频 / 音频下载工具：左侧粘贴链接、选画质，右侧看实时进度。支持批量、播放列表、剪辑双轨拆分、去水印。基于 Python 标准库实现，**无需安装任何第三方包**；也提供打包好的单文件 exe，下载双击即用。

## 功能特性

- **批量下载**：链接框一行一个，支持视频 / 播放列表 / 频道
- **画质预设**：最佳画质、2160P / 1080P / 720P、仅音频 MP3 / M4A，也能自己填 `-f` 表达式
- **解析预览**：先看标题、时长、可用清晰度，点分辨率直接切换画质
- **实时进度**：速度、剩余时间、已下载大小、第几路流，合并 / 转码阶段实时显示
- **任务队列**：默认同时下 2 个（可改），支持取消、重试、打开文件、打开目录
- **高级选项**：整列表下载、字幕（自动字幕 / 嵌入）、封面、元数据、章节、跳过已下载、Cookie、代理、限速、并发片段
- **运行日志**：完整 yt-dlp 原始输出，出错能直接看到原因
- **下载历史**：本地记录，可点开文件
- **一键更新**：页面右上角直接升级 yt-dlp
- **剪辑双轨**：一个链接拆出「纯视频轨 + 纯音频轨」，音画对齐可直接进剪映 / Premiere / 达芬奇
- **去水印**：下载完成后自动用 ffmpeg 处理（区域消除 / 裁边）

## 快速开始

### Windows 用户（推荐，零依赖）

到 [Releases](https://github.com/yuanshen-123uodo/yt-dlp-workbench/releases/latest) 页面下载 **`yt-dlp-workbench.exe`**（约 9MB），双击即用：

- **无需安装 Python**，也无需装任何第三方库
- 首次运行会自动下载 yt-dlp（约 18MB，一次性；之后启动只要 2–3 秒）
- 下载的文件保存在 exe 同目录的 `downloads\` 文件夹
- 用完关掉黑色命令行窗口即可停止服务

### 源码运行（Windows 双击 / 其他平台）

双击 **`启动工作台.bat`**，浏览器会自动打开 http://127.0.0.1:8765 。

- 首次运行会自动下载 `yt-dlp.exe` 到 `bin/` 目录（也优先使用你系统里已安装的 yt-dlp）
- 用完直接关掉黑色命令行窗口即可停止服务

### 其他平台 / 手动启动

```bash
# 依赖：Python 3.8+（仅标准库）；yt-dlp（放入 bin/ 或加入 PATH）；ffmpeg 可选但推荐
python server.py
```

## 依赖说明

| 依赖 | 是否必需 | 说明 |
|---|---|---|
| Python 3.8+ | 源码运行必需 | 只用标准库，不用 pip 装任何东西；**exe 版不需要** |
| yt-dlp | 必需 | 首次运行自动下载；或 [ releases 页面 ](https://github.com/yt-dlp/yt-dlp/releases/latest) 手动放到 `bin/`；或 `pip install yt-dlp` / `winget install yt-dlp` |
| ffmpeg | 强烈推荐 | 高清视频合并音视频、双轨拆分、去水印都靠它。[下载](https://ffmpeg.org/download.html) 后加入 PATH 即可 |

> 1080P 以上或会员内容：在「高级选项 → Cookie 来源」选一个已登录该网站的浏览器。
> YouTube 等站点打不开：在「高级选项 → 代理」填本地代理，如 `http://127.0.0.1:7890`。

详细使用说明见 [使用说明.md](使用说明.md)。

## 工作原理

```
启动工作台.bat → server.py（ThreadingHTTPServer，仅监听 127.0.0.1）
                      ├─ 静态托管 web/ 前端页面
                      ├─ 任务队列 + 调度线程（并发可调）
                      ├─ 子进程调 yt-dlp，--progress-template 解析结构化进度
                      └─ ffmpeg 后处理：双轨抽取 / 去水印
```

全程本地运行，不经过任何远端服务器；服务只监听 `127.0.0.1`，外部设备无法访问。

## 常见问题

- **提示找不到 yt-dlp**：确认 `bin/yt-dlp.exe` 存在，或系统 PATH 里有 yt-dlp
- **提示 ffmpeg 缺失**：装一个加入 PATH（Windows 可 `winget install Gyan.FFmpeg`）
- **下载失败**：先点页面右上角「更新」升级 yt-dlp，站点改版后旧版本常失效
- **页面打不开**：确认是通过 bat 启动的，且黑色窗口没关
